能力
工具内核只有 exec；文件、联网、时间、记忆、进程、PPT 都由插件补上
插件放在 plugins/，每个插件一个 plugin.json 加 tools.py
权限设置 → 能力：帮我批准 / 自动批准 / 完全访问，写进 APPROVAL_MODE
思考强度设置 → 能力：off → ultra，写进 REASONING_EFFORT
记忆memory/ 里的内容会在每次启动时注入系统提示
智能卡片（IUI）

组件card / list / table / buttons / form / chart / callout / progress / carousel / image
交互按钮的 send 会当成一条消息发回模型，href 打开链接
